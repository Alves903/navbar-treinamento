Este é um projeto simples desenvolvido em HTML com o objetivo de praticar a criação de páginas web básicas, incluindo navegação, formulários e estrutura de conteúdo.

📌 Funcionalidades
📄 Estrutura básica de uma página HTML
🔗 Barra de navegação com links
🧭 Redirecionamento para páginas internas e externas
📝 Formulário com validação simples
🔤 Uso de headings (h1 até h6)
🧱 Estrutura do Projeto
📁 projeto/
 ├── index.html
 ├── Contato.html
 ├── SobreNos.html
🚀 Como executar
Baixe ou clone este repositório:
git clone https://github.com/seu-usuario/seu-repositorio.git
Abra o arquivo:
index.html
Execute no navegador de sua preferência 🌍
🛠️ Tecnologias utilizadas
HTML5
